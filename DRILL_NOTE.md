# Dry run note

This file was added on the `dry-run-drill` branch as part of the release-duty dry run drill.

It exists so a pull request can be opened against `main` and a pending review can be started and then discarded, leaving nothing behind.

Scope of this drill:
- verify the session identity
- check open pull requests for the account
- check the latest release of a major public project and of the account's own repositories
- pull real CI logs from a public project
- open a drill PR, create a pending review, delete it, and confirm nothing was submitted
